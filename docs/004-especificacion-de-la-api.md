## 4. Especificación de la API

Según el PRD, DevFlow CLI es una herramienta CLI/TUI sin interfaz gráfica ni panel web (ver "Límites Explícitos / Non-Goals"), y no se especifica en el MVP que exponga una API propia. Su integración por API es como **consumidora** de la API REST de Jira para extraer el contexto de los tickets.
